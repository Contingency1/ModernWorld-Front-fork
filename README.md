## Branch Strategy

**이슈 생성 시 `Assignees`, `Labels`, `Project` 꼭 할당**

### Default Branch

| Name | Description                    |
| ---- | ------------------------------ |
| main | repository default branch      |
| dev  | development environment branch |

### Branch Example

-   feature/titme/#issueNo

예시

-   feature/comment/#1

## Commit Convention

### Commit Example

**{type}/#{issue-number}: 작업한 사항(띄어쓰기 허용)**

예시

-   setting/#3: project set up

### Commit Type

| Type             | Description       |
| ---------------- | ----------------- |
| 🌏deploy         | 배포 관련         |
| ⚙ Setting       | 개발 환경 셋팅    |
| 🐞 BugFix        | 버그 수정         |
| 💻 CrossBrowsing | 브라우저 호환성   |
| ❌ Delete        | 기능, 코드 삭제   |
| 📃 Docs          | 문서 작성 및 수정 |
| ✨ Feature       | 기능 개발         |
| 📬 API           | API 통신          |
| 📝 Modify        | 기능, 코드 수정   |
| 🔨 Refactor      | 코드 리팩토링     |
| ✅ Test          | test 관련         |
| 🙋‍♂️ Question      | 질문 & 요청 사항  |
| 🎨 Publish       | 마크업 & 스타일링 |
